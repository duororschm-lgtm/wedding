# ♥ 星露谷像素风 · 婚礼请柬

一个手机端 H5 电子请柬：像素风开屏信封、8-bit 音乐、故事对话、照片墙、倒计时、
一键地图导航、添加到日历、宾客回执，以及一个**网页编辑器**——
文字、照片、嘉宾名单全部在线修改，**改完即时生效，不用再碰代码**。
支持给每位宾客发**专属链接**（打开自动显示 ta 的名字），
晚上 6 点后自动切换星空夜色主题。

更多亮点：主视觉像素背景 + 花瓣雨 + 视差滚动、婚礼月历、今日行程表、交通指引双卡、
「参加我们的婚礼」任务卡、山谷友人祝福墙（出席宾客头像墙，约 30 种随机像素头像）、
住宿登记（需要住宿则填写入住/退房时间，看板与 CSV 都能看到）、
宾客可随时「修改我的回执」（本机保存编辑凭证，删除旧记录需凭证，防止误删）。
背景音乐文件失效时自动切换到内置 8-bit 合成旋律。

**游戏游园会**：钓祝福（抛竿钓鱼，每条鱼送一句祝福）、种花园（选花浇水，盛开后计入山谷花园总数）、
寻宝集心（6 颗爱心散落在页面各处，集齐有奖励）、像素烟花（点夜空也能放）、
占卜运势（按名字+日期抽签，每人每天固定一支）+ 成就图鉴（右下角奖杯按钮）。
每个小游戏和文案都可以在编辑器的「游戏」页开关和修改。

## 第一步：部署到 GitHub Pages（20 分钟）

1. 打开 https://github.com → 注册/登录账号
2. 点右上角 **+** → **New repository**，名字填 `wedding`，选 **Public** → Create
3. 在仓库页面点 **Add file → Upload files**，
   把本文件夹里**所有文件**拖进去上传（保持文件夹结构）→ **Commit changes**
4. 仓库 **Settings** → 左侧 **Pages** → Source 选 **Deploy from a branch**、
   Branch 选 **main** → 保存
5. 等 1~2 分钟，回到 Pages 页面，顶部会显示网址：
   `https://你的用户名.github.io/wedding/`

**这个网址就是你的请柬链接，发到微信、短信都可以！**

> 💡 更新内容：以后直接传新文件覆盖即可（用编辑器改内容则完全不用重新上传）。

> ⚠️ 如果朋友反馈微信里打开很慢或打不开（GitHub Pages 在国内偶尔抽风），
> 免费替代方案：把同样的文件上传到 [Cloudflare Pages](https://pages.cloudflare.com)
> （注册 → Workers & Pages → Create → Pages → Upload assets，全选文件上传，一分钟出链接）。

## 第二步：开通 Supabase（20 分钟，回执/编辑器/专属邀请都靠它）

所有数据（回执、嘉宾名单、请柬内容、照片）都存在 [Supabase](https://supabase.com)（永久免费档足够用）。

1. 打开 https://supabase.com → 点 **Start your project** → 用 GitHub 或邮箱注册
2. 登录后点 **New project**，名字随便起（如 `wedding`），
   数据库密码随便设一个，地区选 **Southeast Asia**（新加坡，离国内近），
   点 Create project，等 2 分钟初始化完成
3. 左侧菜单点 **SQL Editor** → **New query**，
   把本文件夹 `db/init.sql` 里的内容**整段复制粘贴**进去 → 点 **Run**
   （一次性建好：回执表、嘉宾表、内容表、照片/音乐存储桶、权限）
4. 左侧菜单点 **Authentication** → **Users** → **Add user**：
   - 填一个你的邮箱和一个好记的密码
   - 勾选 **Auto Confirm User**（重要！不勾登录不了编辑器）
   - 点 Create user —— 这就是你的编辑器登录账号
5. 左侧菜单点 **Project Settings**（齿轮图标）→ **API**：
   - 复制 **Project URL**（形如 `https://xxxx.supabase.co`）
   - 复制 **anon public** 那一行的密钥
   - 把这两个填进 `config.js` 的 `supabase.url` 和 `supabase.anonKey`，
     保存后把 config.js 重新上传到 GitHub 仓库（覆盖旧文件），等 1 分钟生效

> ⚠️ 没开通 Supabase 之前，请柬可以正常浏览，但回执表单、专属邀请、
> 编辑器都不可用——所以强烈建议先做完这一步。

## 第三步：打开编辑器，改所有内容

浏览器打开（或微信里点开）：

```
https://你的用户名.github.io/wedding/editor.html
```

用第二步设置的邮箱密码登录。编辑器有四个标签页：

### 📝 内容
新郎新娘姓名昵称、婚礼日期时间农历、酒店名称地址经纬度（经纬度在
https://lbs.amap.com/tools/picker 搜索酒店获取）、开篇故事对话
（每行一条，格式 `发言者|内容`，发言者留空为旁白）、微信分享文案、
背景音乐（可直接上传 mp3）。点保存后**请柬即时生效**，不用重新部署。

### 📷 照片
网页上传婚纱照（自动存云端），可删可增。上传后请柬的照片墙自动显示。

### 👥 嘉宾
输入宾客姓名添加。每人自动生成一个**专属链接**，点「复制链接」发给谁，
谁打开请柬就会看到「♥ 亲爱的 XXX ♥」的专属横幅、信封上写着 ta 的名字、
回执自动填好姓名——数据上也能看到是谁回了、谁还没回。

### 🎮 游戏
开关五个小游戏和成就系统、修改钓祝福的祝福语池、占卜的签文库、
寻宝集心的爱心数量与奖励文案，还能看到山谷花园的种花总数。

### 📊 看板
统计卡片（回执总数 / 确定出席人数 / 未回复嘉宾）+ 回执明细表
（可删除、导出 CSV）+ 未回复嘉宾名单。旧的 admin.html 就是简化版看板，
日常用编辑器就够了。

**访问统计（谁打开了请柬）**：打开次数 / 近 24 小时 / 已打开专属请柬的嘉宾 / 未打开嘉宾。
需要先把 `db/visit-stats.sql` 整段复制到 Supabase SQL Editor 跑一次
（在 init.sql 之后跑，可重复运行）。

## 常见问题

**Q：微信里点开没有音乐？**
A：手机浏览器禁止网页自动出声，拆信封时点一下就开始放了。右上角音符按钮可以随时开/关。

**Q：宾客填了回执，我看不到？**
A：确认 config.js 里 Supabase 两个值都填了且已重新上传、`db/init.sql` 跑过、
且回执页面显示「已有 N 位宾客送出祝福」。还不行就在微信里点右上角「···」→「刷新」。

**Q：专属链接打开没显示名字？**
A：确认该嘉宾已保存在编辑器的「嘉宾」页、链接是复制的 ta 那一行自己的链接、
且 config.js 的 Supabase 密钥已填好生效。

**Q：想改婚礼日期/地点/故事？**
A：直接在编辑器「内容」页改，点保存，请柬立刻更新，不用碰代码。

**Q：链接会过期吗？**
A：不会，GitHub Pages 链接永久有效，除非你删掉仓库。

**Q：晚上打开请柬背景变了？**
A：是设计好的「昼夜主题」：18:00 到早上 6:00 自动切换星空夜色（月亮、星星、深蓝夜空）。

**Q：以后不想被别人填回执了？**
A：把 config.js 里的 supabase 两行清空重新上传，回执表单会自动停用。
